GoDo.txt 3.0 — Keyboard Shortcuts & Help

Navigation
↑/↓ Navigate tasks
Shift + ↑/↓ Select multiple tasks
Ctrl + ↑/↓ Move task up/down in File sort mode
Drag & Drop Reorder tasks (only works in File sort mode)
( Add new task
Ctrl + x Cut selected task(s) in File sort mode
Ctrl + v Paste cut task(s) at the selected task in File sort mode
Task Management
Click Select task
Ctrl + Click Multi-select tasks
Shift + Click Range select tasks
Space
Double click Edit selected task
DEL Delete selected task(s)
x Complete or uncomplete selected task(s). Valid recurring tasks advance instead of receiving an x marker.

Contexts, Projects & Tags
@context A todo.txt context, such as @home or @phone.
+project A todo.txt project, such as +Website or +Personal.
Tags Select multiple tags from the filter menu. The active selections appear below the icon row and disappear when filters are cleared.
Recurring Tasks
r:w05 Weekly on weekday 5, where Sunday is 1 and Saturday is 7.
r:m15 Monthly on the 15th day.
r:05w Every five weeks. Use two digits for the interval.
r:y1225 Yearly on December 25, using MMDD.
Complete When a valid recurring task is completed, the recurrence string stays unchanged, due: advances from the actual completion date, and last: records that completion date. Invalid recurrence strings behave like ordinary tasks.
Archive Workflow
1 Open the folder icon, then choose Set as Archive beside a .txt file.
2 Click the archive icon beside Reload. Completed tasks are appended to the archive and removed from the active todo file.
Note Archiving does nothing until an archive file has been designated. The active todo file and archive file must be different.
